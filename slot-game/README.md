# 🎰 ラッキーセブン スロット

ブラウザだけで遊べる 3リール × 5ペイラインのスロットマシンです。
外部ライブラリを一切使わず、HTML / CSS / JavaScript のみで実装しています。

## 遊び方

`index.html` をブラウザで開くだけで起動します。ビルドもサーバーも不要です。

```
slot-game/
├── index.html   画面構造
├── style.css    見た目・アニメーション
└── script.js    ゲームロジック
```

| 操作 | 内容 |
| --- | --- |
| **SPIN** ボタン / `Space` キー | リールを回す |
| **＋ / −** | 1ラインあたりのベット額を変更（1 / 2 / 5 / 10 / 25 / 50） |
| **MAX BET** | 現在のクレジットで払える最大額にする |
| **AUTO** | クレジットが尽きるか再度押すまで自動で回し続ける |
| **🔊** | 効果音のオン / オフ |
| **クレジットをリセット** | 所持クレジットを 1,000 に戻す |

クレジット・ベット額・フリースピンの残数・音設定は `localStorage` に保存され、
次に開いたときに続きから遊べます。

## ルール

- 有効ラインは常に **5本**（上段・中段・下段・右下がり・右上がり）。総ベット＝ラインベット × 5。
- 1ライン上に同じ絵柄が **左から3つ** 揃うと配当が成立します。
- 🃏 **ワイルド** は他のすべての絵柄の代わりになります。ワイルド自身が3つ揃うと最高配当です。
- 🍒 と 🍋 は **左から2つ** 揃うだけでも少額の配当があります。
- 💎 **スキャッター** は位置に関係なく、画面内に3つ以上出現すると総ベットの2倍を獲得し、
  **フリースピン5回** に突入します。フリースピン中はベット不要で、期間中に再度揃うと回数が追加されます。

## 配当表

1ラインあたりのベット額に対する倍率です。

| 絵柄 | 3つ揃い | 2つ揃い | 出現ウェイト |
| --- | ---: | ---: | ---: |
| 🃏 ワイルド | ×700 | — | 2 |
| 7️⃣ セブン | ×400 | — | 3 |
| 💎 ダイヤ（スキャッター） | ×100 | — | 7 |
| ⭐ スター | ×85 | — | 8 |
| 🔔 ベル | ×42 | — | 12 |
| 🍉 メロン | ×28 | — | 15 |
| 🍊 オレンジ | ×20 | — | 18 |
| 🍋 レモン | ×15 | ×1 | 20 |
| 🍒 チェリー | ×10 | ×1 | 22 |

絵柄はウェイトに応じた重み付き抽選で、各マス独立に決定されます。

## 確率設計

40万スピンのシミュレーションによる実測値です（`script.js` の `evaluate()` をそのまま使用）。

| 指標 | 実測値 |
| --- | ---: |
| 還元率（RTP） | 約 **93.2%** |
| 当選率（1スピンあたり） | 約 **40.5%** |
| フリースピン突入率 | 約 **1.75%**（約57回に1回） |

配当や出現ウェイトを変えたい場合は `script.js` 冒頭の `SYMBOLS` と、
`FREE_SPINS_AWARD` / `SCATTER_PAY_MULT` などの定数を編集してください。

## 実装メモ

- **リールの回転**：ストリップを `[新しい結果, ダミー絵柄, 現在の結果]` の順に並べ、
  末尾から先頭へ `translateY` させることで下方向の回転を表現しています。
  移動量を `%` 指定にしているため、画面幅が変わってもコマがずれません。
- **結果の決定**：演出より先に抽選を確定させ、リールは結果を見せるためのアニメーションとして動かしています。
- **効果音**：音声ファイルを使わず、Web Audio API のオシレーターで生成しています。
  ブラウザの自動再生制限に合わせ、最初の操作時に `AudioContext` を初期化します。
- **アクセシビリティ**：`Space` キーでのスピン、`aria-live` による当選内容の読み上げ、
  フォーカスリングの表示、`prefers-reduced-motion` への対応を行っています。

## 動作確認

Chromium（Playwright）で以下を確認済みです。

- 初期表示・スピン・停止時の DOM 状態、JavaScript エラーが出ないこと
- 3つ揃い / ワイルド代用 / 2つ揃い / スキャッターの判定結果
- 当選マスとライン番号のハイライト、WIN のカウントアップ
- フリースピンの突入・自動消化・終了
- `localStorage` への保存と再読込時の復元
- 幅 360px でも横スクロールが発生しないこと
